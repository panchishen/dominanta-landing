# Доминанта — лендинг

Лендинг для https://dominanta74.ru/. Основа — проект Dental AI. Чистый HTML/CSS/JS, без сборщика.

Превью: **https://panchishen.github.io/dominanta-landing/**. Деплой идёт автоматически при пуше в `main`, если изменилось что-то в `site/`.

## Локальный запуск

```bash
node serve-site.js
```

Откроется на http://localhost:5055.
